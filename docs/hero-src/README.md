# Homepage hero — source

Self-contained Three.js bundle for the LAION-fMRI docs landing page. Source
lives here; the built artifact is committed under
`docs/source/_static/hero/` so the Sphinx build stays Node-free.

## Layout

```
docs/hero-src/                source (this directory)
  main.js                     entrypoint + scene setup
  hero.css                    layout + tokens (mirrors --rv-* vars)
  esbuild.config.mjs          bundler config
  package.json
docs/source/_static/hero/     built artifacts (committed)
  hero.js                     bundled IIFE, exposes window.LaionFmriHero.init
  hero.css                    copy of source CSS
  brain-data.json             ~2000 vertices + faces (lh + rh)
  stimuli_atlas.jpg           1024 stimulus thumbnails packed 32×32
  stimuli_atlas.json          atlas manifest
```

## Rebuild

```bash
cd docs/hero-src
npm install
npm run build
```

Watch mode for iterating on the shader / layout:

```bash
npm run watch
```

## Atlas

The atlas PNG (well, JPEG) is generated by
`docs/scripts/build_stimulus_atlas.py`. Re-run only when the stimulus
set or atlas dimensions change:

```bash
uv run python docs/scripts/build_stimulus_atlas.py \
  --stimuli-root ~/Downloads/LAION-fMRI-stimuli \
  --tile-count 1024 --tile-size 64
```
