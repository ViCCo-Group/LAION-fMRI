# Previous random splits

`random-v1.zip` contains the 25 original per-subject random split files,
unchanged, from commit `ce4b84d944ecfdc9a7b3ee9fb82526b66239882a`.
They were replaced to keep identified duplicate images in the same fold.
Use these files only to reproduce results obtained with the previous splits.
The shared-only random splits and all other split families were unchanged.
